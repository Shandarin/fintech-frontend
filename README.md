# fintect

**React + TypeScript 金融市场状态监控前端 · 独立前端仓库 · 全部为合成数据。**

依据《2026年上海科技大学第一届金融科技竞赛赛题》第7–9页及宣讲说明设计。覆盖数据看板、特征分析、状态热力图、预警、登录和数据权限等前端场景，并增加数据质量、血缘、自定义看板和平台运维交互。

这不是完整竞赛后端：没有真实 MySQL、Redis、Kafka、Flink、微服务、JWT/OAuth2 或服务器性能测试。监控和模型快照明确标记为模拟。不得将这份前端演示作为已满足全部竞赛工程指标的证明。

## 先看效果：无需安装依赖

直接用 Chrome / Edge 打开根目录 **`RegimeLab-preview.html`**。这是同一套 React 源码编译出的完整单文件应用，不是页面截图。无外部 CDN、字体或行情依赖。

某些浏览器限制 `file://` 存储；应用会降级为本次会话保存并提示。要稳定持久化，使用本地 HTTP：

```bash
node scripts/serve.mjs
```

访问 **http://localhost:4173**。这只需要 Node，无需 npm install；使用包内已构建的 `dist/`。

默认进入分析师工作台。右上角头像可切换管理员、分析师、观察员，或退出后体验登录/注册。所有账号和验证码均为本地演示；不要输入真实密码或敏感信息。

## 从源码开发

需要 Node.js ≥22.12、npm，以及首次依赖下载的网络访问。

```bash
npm install
npm run dev
```

访问 **http://localhost:5173**。

```bash
npm test           # 23项纯函数/权限/API/CSV/PCA测试
npm run typecheck  # 使用实际安装的React类型检查
npm run build      # TypeScript检查 + Vite生产构建
npm run preview    # 预览生产构建
npm run build:portable  # 从同一源码重建离线HTML和dist
```

首次 `npm install` 成功后，将真实生成的 `package-lock.json` 提交到你的前端仓库；随后将 CI/Docker 安装改为 `npm ci`。此交付没有伪造锁文件。

### 本次交付的验证边界

交付环境不能访问 npm，因此**未实际执行完整 npm install / Vite 构建**。随包 `dist/` 和 HTML 使用已安装的 TypeScript 5.8.3 与 React 19.1.1 离线运行时构建；已经完成 Chromium 浏览器渲染和交互检查、纯函数测试。Docker 配置、Cloudflare Pages 部署需要在你的网络和账户环境里验证；本次未对外发布网站。

## Docker 一键启动前端演示

安装并启动 Docker Desktop，然后在仓库根目录执行：

```bash
docker compose up -d --build
```

访问 **http://localhost:3000**。默认通过 `Dockerfile.preview` 使用包内预构建产物，只需取得 Nginx 镜像，不需要启动任何后端，也不会连接线上数据库。

从源码构建镜像：

```bash
docker compose -f docker-compose.yml -f compose.source.yml up -d --build
```

此命令需要 npm 与镜像仓库网络。`/healthz` 提供容器健康检查。默认 `/api/*` 和 `/graphql` 返回501而不是假装有真实后端。

**双Repo集成：** 本仓库只维护前端。后端仓库可引用本前端的发布镜像，统一启动网关、三个业务服务和数据基础设施。参见 `deploy/backend.compose.example.yml`（结构例子，镜像地址必须替换）。仅启动本仓库不等于整套竞赛系统启动。

## Cloudflare Pages

连接这一个独立前端仓库，使用以下设置：

| 设置 | 值 |
| --- | --- |
| Root directory | 仓库根目录 |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node版本 | 22，且不低于22.12 |

也可以直接上传现有 `dist/` 静态文件；上传产物根目录应直接包含 `index.html`。应用采用Hash路由，例如 `/#/features`，不依赖服务端路由重写。

`VITE_API_BASE_URL` 只作为 API 工作台真实请求测试的默认地址；**设置它不会自动把全部页面切换到真实后台**。正常页面当前仍由模拟状态驱动。后续接入步骤见 `docs/api-integration.md`。

### 数据与计算说明

- 12个资产名称用于UI示例，价格由固定种子生成，**不是真实市场数据**。
- 行情有260个工作日样本，截至2026-10-09；工作日不是完整的各交易所交易日历。
- 波动率、动量、收益、回撤、相关系数、PCA确实从样本计算，不是只换一组固定数字。
- 状态识别是可解释的本地启发式演示分类器，**不是 GMM/HMM/KMeans 实际模型推理**。模型页面展示命名版本的示例元数据；切换元数据不会偷偷改变计算引擎。
- 自定义特征保存定义和版本，不执行用户输入的代码。真正计算自定义特征要接入后端特征引擎。
- 回测按日期计算条件与未来N日最大回撤事件；未来信息只用于评价标签。未建交易策略，不计算交易成本，忽略通知冷却，不合并重叠事件。
- 模拟实时事件每5秒产生一次，历史行情不会被随机推送改写。没有真正建立WebSocket连接。
- CSV导入保存在本浏览器；不进入行情源、Flink计算或模型。避免把任意上传数据误当成可训练的规范数据。
- 数据源质量数值、特征重要性、服务指标、Checkpoint等为示例快照，不代表真实系统质量或性能。
- 本地角色限制不构成安全边界。真实后端必须重新验证身份、权限和所有参数。

## 项目结构

```text
src/
  components/        导航、弹窗、SVG图表、日期范围
  pages/             十个工作台页面与登录页面
  data/mock.ts       可重复生成的合成数据
  lib/analytics.ts   纯计算：特征、相关性、PCA、规则
  lib/files.ts       CSV解析、安全导出
  state/             模拟业务状态、权限、事件、存储
  services/          模拟API与真实HTTP客户端
  styles.css         响应式视觉系统
public/              图标、静态部署头、OpenAPI草案
scripts/             离线构建、无依赖静态服务、测试
vendor/              带许可证的离线React运行时
Dockerfile           从源码构建
Dockerfile.preview   运行预构建演示
```

没有把两个独立仓库强行合并；后端接入可以按接口契约逐项替换。
