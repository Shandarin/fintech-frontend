# 前后端对接

## 当前数据路径

本次界面重构保留现有 HTTP/WebSocket 服务文件和接口契约：

- `/market-api/v1`：资产、行情、指标、日历、资讯、来源、导入批次及质量检查。
- `/api/v1`：模型、回放会话、市场状态和特征。
- `/ws/v1/regimes?session_id=...`：通知前端重新核对 REST 数据。
- 回放写入仍为 `POST /api/v1/stream/sessions`，请求体保持 `model_id`、`rate: 5`、可选 `from` 和 `to`。

开发和构建预览代理仍由 `vite.config.ts` 管理，市场后端指向 8082，回放后端指向 8080。线上静态站点需要同等反向代理；当前界面不自动替换服务地址。

## 展示规则

1. 只显示真实响应中存在的记录。成功空响应不生成报价、数值、图表、空表格或“暂无数据”卡片。
2. 请求失败显示短错误和重试，绝不调用本地模拟器兜底。
3. 日期、价格、数值和来源缺失时不伪造默认值；页面不会把缺失数值填成 0。
4. 页面级身份模拟已经移除。后端仍负责真实身份验证与授权，显示偏好不提供权限控制。
5. 会话与资产切换时校验结果归属并中止过期请求，避免把旧结果显示在新选择下。
6. API 访问工具直接发送用户填写的 HTTP 请求。写入/删除请求在实际发送前显示明确确认；不会自动提交示例请求。

`AppContext` 现在只管理路由、界面偏好、自选和提示。旧 `data/mock.ts` 与 `services/mockApi.ts` 仅供原有单元测试使用，不在应用入口依赖图内。

## 交付边界

没有增加或改造后端，没有创建账户认证、服务遥测、训练或预警 API。尚未连接真实接口的演示能力已经从主导航和业务流程移除。既有 OpenAPI 文件、服务模块、Vite 代理和部署代理保持不变。
