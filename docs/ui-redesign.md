# 商业金融产品界面重构

## 导航与视觉

- 顶部主导航：市场总览、行情中心、市场研究、市场回放。
- 数据管理、记录溯源、API 访问和显示设置集中于工具菜单；不再把演示运维能力与行情研究并列。
- 纯白背景、白色内容区、橙色强调、深色文字；涨跌使用可配置的红/绿体系。
- 首页提供可直接进入行情、宏观、日历和研报的入口。数据区按实际返回记录出现。
- 行情采用资产目录 + 行情详情；资讯采用标题和日期为主的列表；日历按有事件的日期分组。
- 页面去掉工作台标语、环境标签、教学段落和重复说明。确有必要的口径、来源和技术细节通过 Info、详情抽屉或折叠区提供。

设计参考范围为用户指定的商业产品的信息层级和操作组织，没有复制商标、文章或品牌资产：

- https://seekingalpha.com/
- https://www.fool.com/
- https://www.xueqiu.com/
- https://www.futuhk.com/

## 操作与数据

- `Ctrl/Cmd + K` 搜索现有资产和功能，结果直达正确页面和标签。
- 行情自选只记录 API 返回的实际资产 ID。CSV “导出全部”明确导出完整已加载历史；研究页导出限定当前区间。
- 回放只使用后端模型、会话与结果。页面不会生成模拟状态、假概率或示例特征。
- 创建回放保留原请求体，防止重复提交和旧轮询覆盖新会话；展示结果绑定当前会话。
- 为空时隐藏对应数据区块；失败时保留短错误与重试，不补零、不填演示数据。
- 原有演示账户、预警、权限和服务状态不再恢复到新界面。旧测试夹具仅保留为测试资产。
- API 写入与删除操作保留明确的后果确认。显示设置的恢复操作说明具体变化。

## 可访问性与构建

保留关联表单标签、图标按钮名称、焦点样式、跳转正文链接、键盘切换标签、弹窗焦点处理、图表数值表和减少动画偏好。按钮文字使用比装饰橙色更深的橙色，以保证浅底上的可读性。

便携构建现在会收集各页面导入的 CSS，避免单文件预览丢失页面样式。标准生产构建与单文件应用均重新生成。实际完成的检查及环境限制见 `verification.md`。
