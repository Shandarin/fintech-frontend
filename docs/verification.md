## DOM/状态回归覆盖

这些检查执行生成后的 React 单文件应用，采用 JSDOM；只使用空接口响应或明确失败，没有提供演示行情、模型、特征、资料或账户。

- 空接口不生成报价、统计、图表、空表格；旧浏览器数据不恢复演示账户和预警。
- 主要路由与旧链接安全落地；工具只暴露有实际用途的入口。
- 全局搜索快捷键、直接进入经济日历、Hash 深链接。
- 标签左右键切换与选中状态同步。
- 显示偏好保存、页面重挂载、恢复默认的后果说明与取消。
- Info 首次聚焦/点击能打开，Escape 能关闭。
- 写入和删除请求确认前不发送请求。
- 非法 JSON 显示可编辑的错误，不发送请求。
- 空响应隐藏响应内容卡片，HTTP 状态仍可核对。
- 请求失败后可重试，失败不会被模拟结果替代。
- 输入控件保留关联标签或可访问名称。
- 手机导航的展开、跳转和自动关闭状态。

完整结果见 `ui-contract-results.json`；单元测试输出见 `domain-results.txt`。
