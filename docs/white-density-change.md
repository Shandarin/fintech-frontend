# 商业界面第二轮：白底、清晰主色、紧凑信息密度

本轮只调整外观、排版和图表的**视觉颜色**，基于上一轮 `FinTech-commercial-ui.zip`，未修改 API 客户端、请求路径、接口类型或数据展示条件。

- 主画布、卡片、资讯和研究入口均使用白色背景；用于选择/悬停的低对比度中性灰只影响控件，不承担品牌装饰。
- 品牌橙色 `#f26a21`，可读的交互主色 `#F0520F`，白底文字 `#17212a`，细灰分割线 `#e0e6e9`。不使用暖灰底、渐变、大色块装饰或科技蓝。
- 主导航缩至 56px；主要数据容器上边距 24px；索引快照、筛选、按钮、工具面板、数值表格和新闻行采用紧凑布局。
- 首页四个工具入口从彩色方卡改为同一行的白底轻边框入口；页尾研究入口从大面积彩色横幅改为紧凑跳转行。
- 图表默认主线与趋势标识改用橙品牌色，其余系列用更易区分的紫、玫红、蓝绿与金色；红绿涨跌的含义和设置保持不变。
- 保留表单标签、键盘操作、危险操作确认、API 空结果隐藏及请求失败重试机制。
- “紧凑布局”开关仍可开启进一步收缩表格行距；未开启时的基础布局本身已经比上一版更紧凑。

## 验证范围

1. 原有 Node 单元测试 24/24 通过。
2. 修改过的 TS/TSX 文件通过 TypeScript 语法转换检查，编译 JS 通过 `node --check`，CSS 经解析无错误。
3. `src/services/*`、`docs/openapi.yaml`、`public/openapi.json`、代理配置和锁文件与上一轮交付一致。
4. 此环境无可用 npm 依赖缓存且无法访问 npm registry，无法执行新的 `npm ci`/`npm run build`。随包附带的 `dist/` 和单文件 HTML 基于上一版已构建的**同一业务运行时**，更新了 CSS、图表配色及 favicon；安装依赖后可执行 `npm ci && npm run build` 重建正式产物。
5. Chromium 启动/渲染在当前环境超时，未声称完成浏览器截图、手机真机或真实 API 联调。

运行：`npm ci && npm run dev`。正式部署：`npm run build`，发布 `dist/`。
